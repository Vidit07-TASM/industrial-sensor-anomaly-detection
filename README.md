# Industrial Sensor Behaviour & Anomaly Detection

## 📌 Project Overview
This project focuses on analyzing industrial sensor data to understand machine behaviour and identify unusual patterns that may indicate potential anomalies. It uses Python and unsupervised machine learning techniques to explore sensor data and detect abnormal behaviour.

## 🎯 Objectives
- Analyze industrial sensor data.
- Perform data cleaning and preprocessing.
- Explore patterns and relationships in sensor readings.
- Identify unusual data patterns using clustering algorithms.
- Compare different clustering techniques for anomaly analysis.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 🤖 Machine Learning Algorithms
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN

## ⚙️ Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Analysis
5. Clustering Model Implementation
6. Anomaly Analysis
7. Result Visualization
